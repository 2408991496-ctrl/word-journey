# Word Journey · 英语主题词汇训练

面向初中、高中及大学英语四六级学习者的主题词汇训练网页，帮助学生从认识单词逐步过渡到运用搭配、写句子和完成短文。

支持电脑和手机，无需注册账号，不接入付费 AI API。学习进度保存在当前设备的浏览器中。

## 功能介绍

- **选择词书**：初中、高中、大学英语四级、大学英语六级。
- **主题训练**：校园与学习、朋友与相处、家庭与生活、健康与运动、动物与环境、旅行与出行、志愿与社区。
- **自定义词数**：每组可选择 1—20 个词。
- **四阶段练习**：认识单词 → 学习搭配 → 写句子 → 写作文。
- **多种题型**：英译中、中译英、题干内填空、选择题、连线题、句子与短文表达。
- **学习支持**：提供搭配、句式、参考句子和参考范文；作文题包含明确的内容要点。
- **记录与复习**：自动保存进度，查看历史训练与待巩固词汇。
- **导出报告**：下载文本报告，或通过浏览器打印、保存为 PDF，方便老师检查。
- **备份与恢复**：导出、导入 JSON 备份，迁移学习记录。

## 如何使用

1. 选择词书和主题。
2. 设置本次训练的单词数量。
3. 按四个阶段完成训练，需要时查看提示与参考。
4. 完成后查看学习报告，导出给老师。
5. 下次使用同一设备、同一浏览器和同一网址，继续学习。

## 批改方式

客观题按预设答案进行检查。

写句子、写作文等开放题提供参考表达和自查清单，**不使用 AI 自动评分，也不会因为答案不同于范文就直接判错**。开放表达仍需要学生自查或老师进一步反馈。

报告分别展示客观题表现与开放题完成情况，并记录提示、参考和修改情况。

查阅词库与主题训练题库是两部分：**不是每个可查阅单词都配有完整训练题**。

主题训练内容独立编写，不同词书之间存在复习词汇重叠，不能将各行训练词数相加作为不重复词量。词表为社区整理版本，不代表最新官方考纲的完整覆盖。正式教学使用前，建议结合教材和学生水平校对。

## 数据保存说明

- 学习记录使用浏览器 IndexedDB 保存，不上传学生作答到项目后台。
- 当前没有账号系统、云端同步或教师管理后台。
- 同一浏览器内多人使用会共用记录，不会自动区分学生。
- 换设备、换浏览器、清除网站数据或使用无痕模式，可能无法继续读取原记录。
- 更换网址也会影响记录读取；迁移前请导出 JSON 备份，再到新网址导入。
- 导出的学习报告供教学检查使用，不是经过身份验证或防篡改的考试凭证。
- 托管平台可能保留常规访问日志；浏览器朗读是否联网取决于设备的语音服务。

## 本地开发

技术栈：React 19、TypeScript、Vite、Lucide、IndexedDB。

准备 Node.js 20.19+ 或兼容的较新版本，以及 pnpm。

```bash
# 安装依赖
pnpm install

# 启动开发服务
pnpm dev

# 类型检查
pnpm typecheck

# 运行测试
pnpm test

# 构建生产版本
pnpm build

# 在本机预览构建结果
pnpm preview
```

以终端输出的地址为准。本机地址仅供本机访问，不能直接分享给异地学生。

如果使用包含 dist 文件夹的完整交付版本，Windows 下也可以双击“启动学习.cmd”启动本机服务；关闭服务窗口后，本机网页将无法访问。请通过本机服务或部署后的 HTTPS 地址使用，不要直接双击 dist/index.html。

## 部署到 Vercel

1. 将源码上传到 GitHub，仓库根目录应直接包含 package.json。
2. 不要上传 node_modules、dist 或学生学习备份。
3. 在 Vercel 中选择 **Add New → Project**，导入 GitHub 仓库。
4. 检查以下配置，点击 **Deploy**。

| 配置项 | 内容 |
| --- | --- |
| Framework Preset | Vite |
| Root Directory | 包含 package.json 的项目目录 |
| Install Command | pnpm install |
| Build Command | pnpm build |
| Output Directory | dist |
| Environment Variables | 无需设置 |

部署成功后，将项目的正式域名分享给学生。请使用未登录 Vercel 的浏览器和手机测试，确认可以访问并完成训练。

后续向连接的正式分支提交更新，Vercel 会自动重新部署。保持正式访问网址稳定，有利于学生继续读取原有记录。

本项目使用 hash 路由，无需为训练子页面额外配置 SPA 路由重写。也可将构建后 dist 目录内的文件部署到其他静态网站托管平台，无需另建业务服务器或数据库。

选择托管套餐时请核对使用范围和额度。Vercel Hobby 限个人非商业用途；用于收费教学业务时，应确认适用套餐。正式使用前请测试学生所在网络的访问情况。

参考：[Vercel 的 Vite 部署说明](https://vercel.com/docs/frameworks/frontend/vite)、[Hobby 套餐说明](https://vercel.com/docs/plans/hobby)。

## 项目结构

```text
public/
  assets/              本地图片资源
  dictionaries/        查阅词库及词表许可证
src/
  content/
    words.ts           词书、主题、词汇与搭配
    writing.ts         写作题与参考内容
  lib/
    training.ts        训练生成、答案检查与报告统计
    storage.ts         本地保存、备份校验与导入
  App.tsx              主要页面
  Training.tsx         四阶段训练界面
  GlowTextarea.tsx    输入框光晕效果
  styles.css           基础样式与响应式布局
  v2.css               训练及词书交互样式
scripts/               内容资源维护脚本
tests/                 训练与数据逻辑测试
```

扩充主题训练内容时，修改 src/content/words.ts 和 src/content/writing.ts，并校对题目、答案和参考表达。
