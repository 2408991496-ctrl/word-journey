# Word Journey · 主题词汇训练 V2

一个已经接通训练、本机保存、恢复、报告与备份的响应式网页。无账号、业务后端、AI API 或密钥。

## 直接使用

在 Windows 上双击 **启动学习.cmd**，打开 `http://127.0.0.1:4173`。当前交付包含已构建的 `dist/`，启动学习无需安装项目依赖；只需 Node.js 20.19+（本机 Codex 捆绑的 Node 也可用）。保留服务窗口，关闭它会停止本机访问。

不要双击 dist/index.html：浏览器对本地文件的模块加载、JSON 加载和存储行为有区别，应通过本机服务或 HTTPS 网站使用。

1. 首页开启旅程，选择词书与主题。
2. 拖动1—20词滑块，预览后开始。
3. 认识单词（英译中＋中译英）→ 搭配（嵌入填空、选择、连线）→ 写句子 → 写作文。
4. 卡住时查看搭配、句式和参考；修改后再次提交。
5. 学习报告可打印／保存为 PDF，或下载文本；进度备份另存 JSON。
6. 下次使用原设备、原浏览器、原网址继续；换设备用备份导入。

## 实际内容范围

| 词书 | 本地查阅词目 | 主题训练词义项 | 主题数 |
| --- | ---: | ---: | ---: |
| 初中 | 1,987 | 140 | 7 |
| 高中 | 3,743 | 168 | 7 |
| 四级 | 4,543 | 168 | 7 |
| 六级 | 3,991 | 168 | 7 |

主题：校园与学习、朋友与相处、家庭与生活、健康与运动、动物与环境、旅行与出行、志愿与社区。

词表可以完整搜索查阅；**不是所有查阅词目都配好了完整主题训练**。训练为独立编写的168个词义项，基础词跨阶段复习，不同词书不能简单相加为不重复词量。初中使用基础组；高中及四六级加入进阶词，六级优先进阶词；写作长度与参考内容按阶段区分。词表为社区整理版本，不宣称等于最新官方考纲。需要扩充完整主题题库时，在 `src/content/words.ts` 与 `writing.ts` 增加经过教师校对的内容，而不是自动拼接不可靠的材料。

每次选词优先选择该词书下练习次数较少的词。1词组有5项任务，20词组有66项任务；每个词均有识词及搭配题。拼句、引导表达聚焦部分词，短文不要求用尽全部词。

## 保存、反馈与报告边界

- IndexedDB 保存固定词汇、题目快照、逐次作答、草稿、提示及自查；确认事务完成才显示已保存。
- 同一浏览器多人使用会共用记录，不是分账号系统。无痕、清缓存、换域名或端口都可能导致记录不可用。
- 客观题检查配置的答案；开放表达一律不自动评分，提供参考与自查。不同于范文不会直接判错。
- 报告中客观题首次正确率和开放题状态分开。查看提示、参考和修改均留痕。
- 查看范文不是掌握证明，报告未验证身份，也不是防篡改考试凭证。
- JSON 备份限20MB，导入前检查格式、版本、任务关系与范围，提供冲突处理；默认不覆盖本机重复编号。
- 无内置追踪代码，不上传学生答案。实际网站托管方可能记录访问日志。浏览器朗读可能依赖设备提供的联网语音，可不用。

## 开发

技术栈：React 19、TypeScript、Vite、Lucide 图标、IndexedDB。

```sh
pnpm install
pnpm dev
pnpm typecheck
pnpm test
pnpm build
pnpm preview
```

若使用 npm，可运行 `npm install` 和对应的 `npm run` 命令；本项目提供 pnpm 锁文件。`pnpm-workspace.yaml` 只允许 esbuild 的必要构建脚本。

内容脚本 `scripts/fetch-assets.mjs` 用于重新下载词表和图片，常规开发及构建无需执行；所有生产资源已经本地化。下载后务必核对许可、内容与实际词数。

关键目录：

```text
src/content/words.ts             词书、主题和原创搭配/例句
src/content/writing.ts           有明确要点的写作题及分阶段参考
src/lib/training.ts              分组、固定题目、规则检查与报告统计
src/lib/storage.ts               IndexedDB、备份校验与合并
src/App.tsx                     页面、训练、历史、报告、查阅
src/GlowTextarea.tsx             保留原生光标的轻微光晕
src/styles.css                  设计系统、响应式、打印与减少动态效果
public/dictionaries/             四类本地词表及许可证
public/assets/                   本地摄影图片
tests/training.test.ts           覆盖与数据逻辑验证
dist/                           已构建的网站
start-server.cjs                 零依赖本机静态服务
```

## 部署成可分享链接

执行 `pnpm build` 后，将 **dist 目录内的全部文件** 上传至静态网站托管。构建命令 `pnpm build`，输出目录 `dist`；不需要服务器应用、数据库和环境密钥。应用使用 hash 路由，因此普通静态托管无需为子页面配置复杂重写。

推荐使用 HTTPS。选择托管平台时核对学生所在网络的访问情况、额度、域名与适用备案要求。当前本机地址只在当前电脑有效，**不是可以直接发给异地学生的公网地址**。本交付尚未绑定个人托管账号或正式域名。

固定网址非常重要：域名、子域名、协议和端口变化都会改变浏览器的数据存储来源。迁移前先导出备份。网站更新时保留数据库名称及版本迁移，不清空用户记录。源代码不包含任何学生作答，上传部署包不会包含本机 IndexedDB 数据。

- 依赖许可见各项目；部署前可保留 lockfile，按需求生成完整依赖清单。

## V2 界面更新

训练分为四部分，支持点击阶段切换。填空直接在题干空缺处输入；提示与参考使用弹层，避免挤长页面。桌面训练固定在一个视口内；长作文、历史及手机窄屏内容可在主内容区滚动，操作按钮保持可见。鼠标在某本词书上短暂停留，该书移至中央；触屏保留滑动和点击，键盘保留方向键。移除了鼓励性标语。

旧记录保持原有题目、编号和答案，按四部分归类显示；不会为升级而重新生成旧题。新训练使用双向翻译和新搭配题型。备份格式仍为v1，兼容旧备份；新备份可记录连线答案。
